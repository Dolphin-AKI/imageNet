画像検索ツール
==============

■ 使い方
1. この zip をどこかのフォルダに展開する（日本語や空白を含まないパスがおすすめ。例: D:\ImageSearch）
2. start.bat をダブルクリック
3. ブラウザが開いたら、画面から検索したい画像フォルダを追加する

■ 初回起動について
- Python とライブラリ（約 3GB）、AI モデル（約 5GB）を自動でダウンロードします。
  回線にもよりますが 10〜30 分ほどかかります。2 回目以降はすぐ起動します。
- 「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」を押してください。
- NVIDIA の GPU があれば自動で GPU 版を使います。無くても CPU で動きます（遅め）。

■ 終了
黒いウィンドウを閉じるか Ctrl+C。

■ アンインストール
フォルダごと削除すれば OK です（Python・ライブラリ・モデルもすべてこのフォルダ内にあります）。

■ アップデート
新しい zip の中身を上書きして start.bat を起動してください。
必要なライブラリだけ自動で更新されます。data フォルダ（インデックス）はそのまま使えます。
